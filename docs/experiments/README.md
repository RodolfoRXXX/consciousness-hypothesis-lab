# Experiment documentation

## Scope documents

- [V1 developmental scope](v1-developmental-scope.md) — provisional definition of `Agent(t0)`, minimal body, learning claims, controls, falsifiers, and experimental levels.

Each experiment should have a human-readable protocol before execution.

Minimum fields:

- experiment ID and version
- research question
- hypothesis
- competing explanation(s)
- independent variable(s)
- dependent variable(s)
- controlled variables
- configuration / random seed policy
- procedure
- predefined metrics
- result that supports the hypothesis
- result that weakens or refutes it
- raw result location
- analysis
- limitations
